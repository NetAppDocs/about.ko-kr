[role="lead"]
docs.netapp.com의 모델 컨텍스트 프로토콜(MCP) 서버는 기존 NetApp 문서 및 검색 증강 생성(RAG) 서비스 앞에 표준화되고 에이전트 지원이 가능한 통합 계층을 제공합니다. 이를 통해 AI 에이전트는 REST API 직접 통합이나 사용자 지정 파이프라인 개발 없이 자연어를 사용하여 기업의 기술 지식과 상호 작용할 수 있습니다.



[[use-cases]]
== 사용 사례

NetApp 문서에 대한 구조화된 액세스를 제공함으로써 docs.netapp.com MCP 서버는 AI 에이전트가 다음과 같은 작업을 수행할 수 있도록 지원합니다.

* 관련 문서 찾기
* 문서의 전체 내용을 검색합니다.
* 문서 기반 답변 생성 (RAG 기반 답변 생성)
* 근거 있고 검증 가능한 답변을 제시하십시오.


docs.netapp.com MCP 서버를 사용하여 다음 작업을 수행할 수 있습니다.

* NetApp 콘텐츠를 활용하여 에이전트 기반 개발 환경을 개선하십시오.
* 신뢰할 수 있는 문서가 필요한 엔지니어링 및 지원 워크플로를 지원합니다.
* 사용자 지정 검색, 검색 결과 추출 또는 RAG 통합을 구축하고 유지 관리해야 하는 필요성을 줄입니다.
* 공식 NetApp 문서를 근거로 답변을 제공하십시오.




[[how-the-docs-netapp-com-mcp-server-works]]
== docs.netapp.com MCP 서버 작동 방식

MCP 서버는 공식 NetApp 문서에 대한 인터페이스 역할을 하며 게시된 콘텐츠에서 근거 있는 답변을 반환합니다.

. AI 에이전트가 MCP 서버에 요청을 보냅니다.
. MCP 서버는 관련 문서를 검색합니다.
. 이 시스템은 구조화되고 근거 있는 응답을 반환합니다.




[[requirements]]
== 요구 사항

* MCP 서버에 액세스하려면 구독 키가 필요합니다. 키를 요청하려면 사용 사례에 대한 간략한 설명과 함께 ng-docs-mcp@netapp.com으로 문의하십시오.
* 지원되는 클라이언트에는 GitHub Copilot이 포함된 Visual Studio Code, Claude Desktop, Cursor 및 Python 기반 에이전트 프레임워크 등 MCP 호환 환경이 포함됩니다.
* 적용 가능한 NetApp 문서의 이용 약관 및 액세스 거버넌스 정책을 준수해야 합니다.




[[limitations]]
== 제한 사항

* MCP 서버는 docs.netapp.com에 게시된 콘텐츠를 조회합니다. 개인 테넌트 데이터나 내부 사용자 프로필 정보에는 액세스하지 않습니다.
* 제공되는 콘텐츠는 docs.netapp.com에 게시된 콘텐츠로 제한되며 제품 원격 측정 데이터, 클러스터 상태 또는 기타 환경별 데이터 소스를 대체하지 않습니다.
* 클라이언트 에이전트가 사용 가능한 툴을 활용하고 검색 결과를 후속 처리하는 방식에 따라 응답 품질이 영향을 받을 수 있습니다.
* 해당 서비스는 확장 가능한 클라우드 인프라에 상태 비저장 방식으로 배포되므로 지연 시간과 최신성은 하위 문서 및 RAG 서비스에 따라 달라집니다.
